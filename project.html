Executive Summary

As a Site Reliability and Platform Engineer, I designed and deployed jerrymoo.com to demonstrate production-grade cloud architectural principles: high availability, global edge performance, zero-trust storage security, and serverless telemetry.

Rather than relying on traditional monolithic web servers that require ongoing operating system patching, capacity scaling, and vulnerability management, this site leverages a fully serverless AWS architecture. Content delivery is offloaded to Amazon CloudFront edge locations worldwide, while real-time visitor telemetry is processed by AWS Lambda and Amazon DynamoDB.

End-to-End System Architecture

The system is decoupled into two primary layers: a static edge-cached presentation layer and a serverless telemetry backend API.

Deep Dive 1: Zero-Trust S3 & CloudFront OAC Hardening

A common vulnerability in static site hosting is exposing S3 buckets directly to the public internet via open bucket policies. To enforce zero-trust origin security, direct public read access to the S3 bucket is completely disabled.

Instead, access is restricted using CloudFront Origin Access Control (OAC). The S3 bucket policy strictly permits s3:GetObject calls originating exclusively from the specified CloudFront Distribution ARN: 

{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "AllowCloudFrontServicePrincipalReadOnly",
      "Effect": "Allow",
      "Principal": {
        "Service": "cloudfront.amazonaws.com"
      },
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::jerrymoo.com/*",
      "Condition": {
        "StringEquals": {
          "AWS:SourceArn": "arn:aws:cloudfront::123456789012:distribution/E2XYZEXAMPLE123"
        }
      }
    }
  ]
}

Deep Dive 2: Atomic Visitor Telemetry (Lambda + DynamoDB)

To track unique visitor impressions across global traffic without suffering from read-modify-write race conditions, the backend uses DynamoDB's native atomic update expressions.

When a visitor hits the homepage, client-side JavaScript fires an asynchronous REST request to API Gateway. AWS Lambda executes an in-place ADD #c :inc operation directly on the DynamoDB key, guaranteeing thread-safe, sub-millisecond atomic increments even under concurrent load: 

// Production Node.js 20 Lambda Handler (Visitor Counter API)
const { DynamoDBClient } = require("@aws-sdk/client-dynamodb");
const { DynamoDBDocumentClient, UpdateCommand } = require("@aws-sdk/lib-dynamodb");

const client = new DynamoDBClient({ region: "ap-southeast-1" });
const docClient = DynamoDBDocumentClient.from(client);

exports.handler = async (event) => {
    const params = new UpdateCommand({
        TableName: "VisitorCount",
        Key: { id: "main" },
        UpdateExpression: "ADD #c :inc",
        ExpressionAttributeNames: { "#c": "count" },
        ExpressionAttributeValues: { ":inc": 1 },
        ReturnValues: "UPDATED_NEW"
    });

    try {
        const response = await docClient.send(params);
        return {
            statusCode: 200,
            headers: {
                "Access-Control-Allow-Origin": "https://jerrymoo.com",
                "Access-Control-Allow-Methods": "GET, OPTIONS",
                "Content-Type": "application/json"
            },
            body: JSON.stringify({ count: response.Attributes.count })
        };
    } catch (err) {
        console.error("DynamoDB Update Error:", err);
        return { statusCode: 500, body: JSON.stringify({ error: "Telemetry Update Failed" }) };
    }
};

Deep Dive 3: Route 53 Alias Routing & Edge Caching

Domain resolution for jerrymoo.com is managed by Amazon Route 53 using an A (Alias) record. Unlike standard CNAME records, Alias records point directly to the CloudFront distribution root node without incurring additional DNS lookup latency hops.

  • TLS Security: Certificate managed via AWS Certificate Manager (ACM) enforcing TLS 1.3 encryption and HTTP to HTTPS 301 redirection.
  • Cache Control: Static assets (JS, CSS, images) configured with Cache-Control: max-age=31536000, immutable, allowing CloudFront edge nodes to serve responses in under 45ms across Asia-Pacific and global PoPs.

SRE Operational Takeaways

  • High Reliability: Multi-AZ redundancy built into CloudFront and DynamoDB ensures fault-tolerant operation without single points of failure.
  • Cost Optimization: Serverless pay-per-request pricing keeps infrastructure costs near zero while remaining capable of handling sudden traffic spikes.
  • Infrastructure as Code: Deployment configurations captured cleanly for repeatable staging and production environments.
